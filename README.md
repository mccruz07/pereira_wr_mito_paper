# pereira_wr_mito_paper
CellProfiler pipelines and fine-tuned Empanada model for quantitative mitochondrial analysis in TEM images.


Analysis resources for quantitative mitochondrial ultrastructure assessment in transmission electron microscopy (TEM) images. The repository contains the CellProfiler pipelines used for image preprocessing and quantitative feature extraction, together with the fine-tuned Empanada mitochondrial segmentation model based on mitonet_v1_mini. These resources support the reproducible workflow used for mitochondrial segmentation, quality control, and extraction of morphological, intensity, granularity, and texture features.
